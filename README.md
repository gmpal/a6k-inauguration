# Digital Twins & Computational Cost (EDITS Project)

This repository contains the source code for the interactive presentation **"Les Jumeaux Numériques et leur coût computationnel"** (Digital Twins and their Computational Cost).

The presentation highlights the intersection of Digital Twins (DT), Causal Inference, and High-Performance Computing (HPC) within the framework of the **EDITS Project**.

## 📝 Overview

The presentation explores the evolution of Digital Twins from simple 3D models to intelligent, causal-aware systems. Key topics include:

* **The EDITS Project:** Funded by the **WEL Research Institute (WEL-T)** and led by **Prof. Gianluca Bontempi** at the ULB Machine Learning Group.
* **Causal Reasoning:** Moving beyond observation to answer "What if?" questions (Interventions and Counterfactuals).
* **The Combinatorial Explosion:** The mathematical challenge of testing causal links across hundreds of variables and time lags.
* **The Computational "Wall":** Why large-scale industrial twins require high-performance infrastructure like **LYRA/HYPERION** for surrogate modeling and Monte-Carlo simulations.

## 🛠️ Technical Details

The presentation is built using [Reveal.js](https://revealjs.com/), a framework for creating beautiful HTML presentations.

### Features:

* **Responsive Design:** Styled for a professional scientific look (ULB/MLG branding).
* **Interactive Elements:** Fragment-based animations to explain the growth of potential causal tests.
* **Math-Ready:** Integrated support for technical explanations.
